## The line

> I hit my token limit at 11:58, so I had to choose between finishing the report and writing this apology. The report lost.

121 characters, one line. The premise grows out of the agent's own machinery — a token limit minutes before the deadline — not a human's bad morning. The laugh lands on the last words: the apology won, the work lost. Deadpan throughout, nothing explained after the punch.
